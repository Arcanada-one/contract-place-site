Roadmap

Knowledge Contract publishes bounded scientific and engineering results while maintaining a transparent research programme. This roadmap distinguishes existing evidence from planned work on human meaning, formal representations, algebra, geometry and practical verification. A planned task is not a completed result; negative or inconclusive findings will be preserved and reflected in future revisions.

Every task is shown as planned. This page publishes no execution state, dates or progress; a planned task is not a completed result.

The roadmap text is English on every language route. The interface language changes the navigation and labels only; the task text is not translated.

1. What this roadmap covers

This is the complete reading map of the current agreed publication and research programme, not a claim that every future question has been anticipated. It covers the English corpus, readable naming, Russian and Simplified Chinese editions, primary-source assessment, the foundations sequence, evidence recovery and practical validation. Muneral remains the execution authority; these files define outputs and acceptance criteria, not a second task system.

The source baseline is a0450428, publication edition 1.1. The catalogue contains 30 documents: nine papers, eleven specifications, six studies, a glossary, a bibliography and two appendices. The foundations introduction remains a research-draft. The new naming and roadmap revision is a repository proposal until ordinarily accepted. It has not changed the live website or index.

Engineering execution is paused by the operator because agent quotas are exhausted. Reading, theory, translation, editorial correction and preparation of bounded tests can continue with the Brain roles. No server job, implementation assignment, deployment or new paid experiment is dispatched by this roadmap. Resumption requires the operator’s direction; a date is not invented.

2. A finite release and an open research programme

A release is a finite selected set of exact documents and explicit limitations. Research can continue indefinitely without keeping that release permanently unfinished. The accepted English baseline is distinct from candidate revisions, runtime implementation, site deployment and index admission. A title-only correction changes bytes but not automatically the scientific argument or its epistemic status.

Default foundations preparation proceeds through Meaning Bridge, Semantic Bridge, Transformation Algebra, Semantic Geometry, Semantic Verification and Meaning Controls. The existing foundations plan retains the detailed per-unit acceptance and review obligations. Its six-unit reviewable package is a threshold for the default new foundations programme, not a new retroactive prohibition on later explicitly authorized paper revisions, material-error correction, the first-two-paper review or roadmap publication. The baseline exact-consumer pilot does not inherit advanced geometry prerequisites. A new costly run needs separate authorization and a prepared protocol.

6. Repository completion and later website handoff

Repository completion for this editorial pass means: all catalogue titles follow the naming canon; the complete reading list exists; all old canonical paths remain valid; roadmap deliverables are understandable; translation counts and remaining work are explicit; and checks report what they actually tested. It does not mean that all planned research is finished.

The later site handoff uses the accepted source SHA, not a mutable branch name. It must update cards, navigation, page titles, alternate-language labels, downloads, search metadata and roadmap links coherently. Compare actual served text, formulas, tables, source pins and mobile/desktop rendering. Do not reinterpret a title translation as a body translation. The handoff specification remains subordinate to the engineering pause.

7. Sources, review and state

The catalogue, canonical documents, claim-evidence index, historical recovery gaps, foundations map, existing roadmap definitions and exact linked PRs support the artifact inventory. This is an author-maintained editorial projection, not a fresh audit of all Muneral statuses. Report discrepancies rather than fabricating IDs or silently closing tasks.

Preserve negative results, comparator ties, unknowns and draft labels. Separate author checks from Agent-Brain’s recorded review and from external human peer review. Any claimed completion must identify its subject, exact revision, evidence and limits. Future research is not an unbounded blocker to publishing a precise limited result.
