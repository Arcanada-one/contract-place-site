Integration availability

The project already exposes a public read API and an MCP endpoint. These access routes do not establish scientific validity or grant action rights.

Public read API

The documented read routes are search, related and fetch. Compare a response’s source revision with the publication edition.

api.contract.place/health
Available
GET https://api.contract.place/v1/search?q=knowledge&limit=10
GET https://api.contract.place/v1/related
GET https://api.contract.place/v1/fetch

Only the search request above is complete. Related and fetch require their documented parameters. The API accepts browser requests only from contract.place; this site’s document search uses it, other origins should use an HTTP client.
