知识供给

来源如何成为 Knowledge Contract 产物——当前可用与仍在计划中的部分。

知识供给链：数字化 → 转换 → 带图像与图谱的 Markdown → Source Library → 索引 → Knowledge Contract 产物。本站发布不等于运行时准入；图书包不会自动进入 Talomnia KC2。

1. 数字化 — Doclab Arcana

当前可用（已测）Doclab Arcana 是数字化环节：扫描件变为带页锚点的 Markdown、真实图像与逐页损坏报告。OCR 降级与转换网格的 hermetic 代码残留已作为评审叶子存在。
可用
计划中 / 未测为可用机群未测量 Apple Silicon 上的 Doclab OCR 台架（NOT_MEASURED）。不宣称清洁的 empty-damage 公版图书包。
尚未连接

另见

2. 转换 — Conversion Arcana

当前可用（已测）Conversion Arcana（doc-md-html）是第 2 步。公共 API health 已响应（测得 HTTP 200）。办公及相关格式的共享适配器已有评审残留。
可用
计划中 / 未测为可用合成 conversion smoke（/api/v1/health/conversion）尚未上生产（测得 404）。付费上传仍在 Auth/Billing 之后，不宣称可用。
尚未连接

另见

3. 带图像与图谱的 Markdown

当前可用（已测）数字化图书保留带页锚点的 Markdown 与原始图像。图书包与编译产物的工程规范已在本站发布。
可用
计划中 / 未测为可用不宣称每本书的图谱已作为已准入的 Knowledge Contract 运行时对象可用。公式、整表与脚注恢复仍属 Doclab 计划。
尚未连接

另见

4. Source Library

当前可用（已测）私有图书库保存已完成的 Doclab 包。本站 Books 页仅列出已发布的 ContractPlaceLibraryIndex 钉扎——当前零已发布行，不虚构清洁书名。
可用
计划中 / 未测为可用X5 导出残留仍为 DAMAGED（非清洁 empty-damage 包）。该候选的生产获取未测为可用。
尚未连接

另见

5. 索引

当前可用（已测）已发布研究语料可通过本站文档搜索所用的公共 read API 检索。集成可用性已有文档。
可用
计划中 / 未测为可用不宣称 Doclab 图书包已索引进实时 Source Library 架或出版语料之外的面向智能体的索引。
尚未连接

另见

6. Knowledge Contract 产物

当前可用（已测）Knowledge Contract Arcana 在 contract.place 发布研究、规范与研究项。Doclab 命令路径可将图书导出为 Knowledge Contract 包候选。
可用
计划中 / 未测为可用KC-1 图书包不会自动进入 Talomnia KC2。不宣称 KC2 准入与清洁 X5 empty-damage 包（NOT_MEASURED / FAIL 残留）。实验室 Knowledge Journey 外壳是单独的未连接 UI 残留。
尚未连接

另见

复用 Doclab Tesseract / CONV / X3–X6 残留；不虚构 X5 清洁包与 KC2 准入。
