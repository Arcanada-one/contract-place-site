沿执行记录切分证据：一项研究显示，与来源对齐的单元比固定词元窗口更常给出完整支持

七位研究者探讨智能体执行过程的记录结构何时有助于其记忆检索证据。在2,000个查询上，与工具参数和输出对齐的单元把完整证据放进2,048词元预算的比例，比512词元窗口高19.07个百分点；图步骤又增加4.55个百分点，主要来自证据跨越多个事件的情形。我们把这一结果留作参考，没有作任何改动。

项目动态contract.place2026年11月16日

依赖多条证据的论断，只有当所有证据都摆在读者面前时才算得到支持。2026年9月22日提交的一项研究把这一标准用于智能体记忆：在严格的词元预算下，检索能否送达每一条所需证据，执行过程的记录结构又是否有帮助？

问题与度量

Yiqi Wang、Jinqian Ju、Jiaqi Zhang、Zequn Sun、Yiqun Duan、Mingkai Zheng 和 Taotao Cai 把对智能体执行历史的检索看作证据补全。每一项所需证据都是原始执行记录中的一个精确片段，每个检索到的候选都映射回同一套来源坐标，因此组织方式不同的候选可以对照同一批证据来评分。

他们的主要度量 Full Support 问的是：在词元预算内的检索候选是否覆盖了每一个所需片段。作者的理由是，部分证据通常得不出正确答案。

语料库 ISETrace 是合成的：意图和交互由生成得到，工具调用则在隔离的操作系统环境中实际执行。一个语言模型针对1,207次留出的执行写出2,000个查询，每个查询带有一处或多处取自工具参数或输出的精确引文；引文只有在其来源事件中能唯一定位时才被接受。测试集包含641个直接查询、906个关联查询和453个多事实查询。

来源：Yiqi Wang, Jinqian Ju, Jiaqi Zhang, Zequn Sun, Yiqun Duan, Mingkai Zheng, Taotao Cai, "When Does Execution Provenance Help Agent Memory Retrieval?", arXiv:2609.25913v1，2026年9月22日，arxiv.org/abs/2609.25913v1。

跟随来源的单元胜过固定窗口

通常的候选是固定长度的词元窗口。作者改用工具参数和输出来构造候选，并称之为溯源单元。两边使用同一个微调过的稠密评分器时，溯源单元在2,048词元预算下的 Full Support 比512词元窗口高19.07个百分点。即使与一个为每项指标分别挑选四种窗口大小中最优者的理想上限相比，它们仍高出11.96个百分点；作者称这一设置比任何单一的可部署配置都强。

缩小窗口救不了扁平视图。把窗口从512词元减到128词元，使2,048词元下的 Full Support 提高7.11个百分点，但证据因此分散到更多各自排序的候选中，靠前位置的排序变差。

作者自己限定了这一结论。两种视图并不是同一段文本的不同切法：扁平视图包含自由形式的消息和推理，而溯源单元只限于工具参数和输出。他们把这一差距表述为候选视图的效应，而不是对切分方式的纯粹估计。

来源：同一论文，摘要和关于候选视图的结果，arxiv.org/abs/2609.25913v1。

图的增益主要集中在跨事件证据

为了单独考察图的作用，作者固定候选及其稠密得分，再加上一个沿单元之间类型化链接学习得到的修正项。它使2,048词元下的 Full Support 增加4.55个百分点，95%区间为2.98至6.18。

按查询类型拆分，直接查询的增益为0.19个百分点，区间包含零；关联查询为4.00，多事实查询为11.83。相比之下，通过实体共现图扩展扁平片段的做法，在其主表的任何一项预算指标上与关键词检索的差距都不超过1.1个百分点。

难的情形依然难。在多事实查询上，图方案在2,048词元下的 Full Support 为62.25，因此按作者的说法，仍有超过三分之一的多事实查询得不到完整支持。

来源：同一论文，关于图条件修正项的结果，arxiv.org/abs/2609.25913v1。

完整的证据能否带来更好的答案

在预先指定的315个关联查询和多事实查询上，一个看不到方法名称的评审给出的严格答案准确率为：扁平窗口71.75%，溯源单元75.56%，图方案77.78%。直接提供精确证据时为86.35%；不提供证据时为1.27%。

图方案与扁平窗口之间的差距为6.03个百分点，95%区间为0.00至12.10。作者称这是处于临界的证据，并把支持度与准确率之间的联系描述为机制上的一致，而不是已确立的因果关系。

来源：同一论文，下游答案研究，arxiv.org/abs/2609.25913v1。

作者说明的局限

查询由语言模型根据选定的来源材料写成。一名人工验证者复核了模型对其中500个查询的判断，没有在不知情的条件下重新标注；修正后，标准证据在96.0%的查询上准确，在96.2%的查询上完整，人工判定的查询类型与原定类型在77.8%的查询上一致，因此三种类型标签带有噪声。图是根据可观察的调用与返回结构编译出来的，作者说明其中的链接并不证明语义上的因果关系。在经过审核的版本冻结之前，他们不把该数据集作为社区基准提出，并提醒说，如果没有访问控制和脱敏，对精确历史的检索可能暴露敏感内容。

来源：同一论文，局限与伦理考量，arxiv.org/abs/2609.25913v1。

我们从中得到什么

我们没有复现其中任何一个数字，Knowledge Contract 也没有因这项研究而发生任何改变。

有两点与我们保留来源地复用知识的工作相关。第一是度量：统计所需证据是否全部到达，而不是是否找到了某个相关片段，这与核查一条已绑定来源的论断应有的方式一致。第二是效应的先后：证据单元的形态比图步骤重要好几倍，而在这项评估中，图步骤的收益主要集中在证据跨越多个事件的情形。

我们的评估把这篇论文留作参考，并提议做一个有界试验：在40至100条预先选定的合成轨迹上，在相同语料、相同访问权限和相同的2,048词元上限下，比较与来源对齐的证据单元和固定窗口，并对精确片段的完整性和经独立核查的答案准确率评分。在成本对等的基线支持之前，图运行时保持搁置。目前的状态是已提议，尚无负责人接受。

来源：Yiqi Wang, Jinqian Ju, Jiaqi Zhang, Zequn Sun, Yiqun Duan, Mingkai Zheng, Taotao Cai, "When Does Execution Provenance Help Agent Memory Retrieval?", arXiv:2609.25913v1，arxiv.org/abs/2609.25913v1。
