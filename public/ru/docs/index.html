Спецификации

Десять черновых спецификаций, на которые опираются опубликованные работы. Сохранены их идентичность, статус, утверждения и ограничения.

Модель знаний

У проекта уже есть публичный API чтения и MCP endpoint. Доступ к материалам не подтверждает научную состоятельность и не даёт прав на действия.

Доступность интеграций

Исследования на уровне концепций с ограниченными конечными проверками. Это не принятый стандарт и не подтверждённый продукт. Независимая семантическая проверка остаётся открытой.
